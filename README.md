### 📖 Dictionary App

A full-stack dictionary web application with a separate frontend and Node.js/Express API.

- **Stack:** Node.js, Express, Vite, MongoDB/Mongoose
- **Authentication:** JWT and bcryptjs
- **Integration:** Gemini API
- **Deployment configuration:** Render for the backend and Vercel routing

Run locally:

```bash
npm run install:all
npm run dev
```

Configure the required environment variables in a `.env` file before starting the app.
